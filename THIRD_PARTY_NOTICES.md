# Third-party components in StageHand

StageHand is MIT licensed (see the LICENSE file). The app contains the components below as well, each under its own license, whose full text follows. Versions are the ones pinned in this repository. Every binary package includes this file.

| Component | Version | License | Used for |
|---|---|---|---|
| [CLAP](https://github.com/free-audio/clap) | 1.2.10 | MIT | the plugin API headers |
| [DPF (DISTRHO Plugin Framework), Unlikelyware's fork](https://github.com/erickampman/DPF) | 02449d69 | ISC | the plugin window (its DGL library only) |
| [pugl, Unlikelyware's fork](https://github.com/erickampman/pugl) | aa9bf1b8 | ISC | windows and events, inside DPF |
| [NanoVG, with fontstash](https://github.com/memononen/nanovg) | in DPF | zlib | drawing the user interface, inside DPF |
| [stb_image and stb_truetype](https://github.com/nothings/stb) | in DPF | Public domain (or MIT) | image and font loading, inside NanoVG |
| [DejaVu Sans font](https://dejavu-fonts.github.io/) | in DPF | Bitstream Vera / DejaVu (free) | the interface text, embedded by DPF |
| [Karla font](https://github.com/googlefonts/karla) | Regular | SIL OFL 1.1 | the title, embedded from resources/fonts/Karla-Regular.ttf |

Also from Unlikelyware, under the same MIT license: uw-core.

On Linux it links ALSA, JACK, X11 and OpenGL, from the user's system and not included here.

A change that adds a third-party component, or moves one to a new version, updates its row and its license text here in the same commit.
